# Aniyomi Fork

### Full-featured player and reader, based on ~~Tachiyomi~~ Mihon.
Fork with Keiyoushi index.pb repository support and extension crash fixes.

[![CI](https://github.com/Yass5002/aniyomi-fork/actions/workflows/build_push.yml/badge.svg)](https://github.com/Yass5002/aniyomi-fork/actions/workflows/build_push.yml)
[![Latest Release](https://img.shields.io/github/v/release/Yass5002/aniyomi-fork?label=Release&labelColor=06599d&color=043b69)](https://github.com/Yass5002/aniyomi-fork/releases/latest)
[![License: Apache-2.0](https://img.shields.io/github/license/aniyomiorg/aniyomi?labelColor=27303D&color=818cf8)](/LICENSE)

## Download

Get the latest APK from the [Releases](https://github.com/Yass5002/aniyomi-fork/releases) page.

*Requires Android 8.0 or higher.*

## Features

<div align="left">

* Support for Mihon extension-lib 1.6 and Protobuf (`index.pb`) extension repositories (Keiyoushi).
* Runtime crash handling for third-party extensions.
* Updated ProGuard rules for Zstandard (`zstd`), `kotlin.time`, `kotlinx.datetime`, and Injekt.
* Local reading and watching of content.
* A configurable reader with multiple viewers, reading directions and other settings.
* A configurable player built on mpv-android with multiple options and settings.
* Tracker support: [MyAnimeList](https://myanimelist.net/), [AniList](https://anilist.co/), [Kitsu](https://kitsu.app/), [MangaUpdates](https://mangaupdates.com), [Shikimori](https://shikimori.one), [Simkl](https://simkl.com/), and [Bangumi](https://bgm.tv/) support.
* Categories to organize your library.
* Light and dark themes.
* Schedule updating your library for new chapters/episodes.
* Create backups locally to read/watch offline or to your desired cloud service.
* Plus much more...

</div>
